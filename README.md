<h1>🧾 Gerenciador de Senha utilizando Singleton</h1>
<p>Em um pequeno restaurante familiar que prepara marmitas, os atendimentos se tornavam confusos quando havia um grande fluxo de clientes. 
  Frequentemente, pedidos eram atendidos fora de ordem ou clientes esperavam mais tempo do que o necessário, gerando insatisfação e desorganização.</p>
<p>Para resolver esse problema, o programa foi desenvolvido com o objetivo de gerenciar senhas de atendimento. 
  Ele organiza a ordem de chegada dos clientes por meio de uma fila de senhas, garantindo que todos sejam atendidos de forma justa, prática e organizada.</p>
